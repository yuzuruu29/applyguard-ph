`npm run dev` starts the Vite dev server; `npm run build` produces `dist/` consumed by both Capacitor and the deploy scripts; `npm run cap:add && npm run cap:sync && npm run cap:ios|android` opens Xcode/Android Studio; `npm run deploy:vercel` / `npm run deploy:netlify` push the built SPA; Supabase edge functions are deployed automatically on push to `main` touching `supabase/functions/**` via the CI workflow.
