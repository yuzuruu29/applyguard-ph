This repo is a flat monorepo with two sibling code areas: `frontend_app` (the Vite/React SPA) and `supabase/functions` (Node edge functions for checkout/paymongo/cancel). The root `package.json` owns all shared scripts (`dev`, `build`, `test`, `cap:*`, `deploy:*`) so every child is built from the same workspace. `vite.config.js` is the single source of truth for the build pipeline — it registers the React + Tailwind v4 plugins, points Capacitor's `webDir` at `dist`, and includes tests from both `src/` and `supabase/functions/_shared/`. `capacitor.config.ts` wraps the static `dist` output as a native app (splash/status bar, mixed-content flags). Two cloud providers are supported in parallel via `netlify.toml` (SPA redirect to `index.html`) and `vercel.json` (Vite framework detection, rewrites, immutable asset caching, service-worker headers). A GitHub Actions workflow (`supabase.yml`) runs `npm test` then deploys each function under `supabase/functions/**` to the configured Supabase project using the CLI. The only runtime boundary between children is the Supabase JS client calling HTTP edge-function endpoints; there is no shared package or internal API layer.
