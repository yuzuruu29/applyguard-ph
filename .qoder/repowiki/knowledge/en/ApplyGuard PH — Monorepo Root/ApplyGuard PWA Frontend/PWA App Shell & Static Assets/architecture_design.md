Single-page application shell centered on `index.html`, which declares Open Graph + Twitter Card metadata, loads Google Fonts via preconnect, and mounts two module scripts: `/src/mobile.js` (Capacitor bridge, loaded before the React bundle so native apps can intercept early) and `/src/main.jsx` (React root). The `public/` directory holds all browser-resolved resources consumed by the shell and service worker: `sw.js` implements a versioned (`applyguard-v2`) cache-first strategy for static assets and network-first for navigation with old-cache cleanup; `manifest.webmanifest` configures standalone display, share_target for receiving shared job text, and SVG maskable icon; `_redirects` is a Netlify/Vite dev-server wildcard rule routing every path to `/index.html` for SPA client-side routing. Dependency direction is one-way — the shell references these public files by absolute URL, and nothing in this scope imports from the rest of the frontend codebase.
