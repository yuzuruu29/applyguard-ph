Three independent React function components under `src/components/` that are mounted by the app router rather than sharing a sub-package:
- `MockInterviewPage.jsx` — premium-only entry gate (redirects non-premium to `/offers`), owns camera/mic via `getUserMedia`, Web Speech API (`SpeechRecognition` + `speechSynthesis`) for live Q&A, and posts conversation history to the Supabase Edge Function `ai-proxy` with feature `interview_voice`.
- `ResultView.jsx` — read-only result renderer; pulls data from `useApp()` store or `useParams().id` (supports an in-memory `preview` route), renders score ring, breakdown bars, hard/soft flags, missing-info list, next-action card, and embeds the premium `AiAssistant` component at the bottom.
- `OffersPage.jsx` — pricing/checkout page that conditionally wraps its content in `@paypal/react-paypal-js`'s `PayPalScriptProvider` when `VITE_PAYPAL_CLIENT_ID` is set, then drives `createPayPalOrder` / `capturePayPalOrder` from `lib/billing.js` and refreshes entitlements via `refreshEntitlement()` on success.

Dependency direction: these pages depend outward on `../auth.jsx`, `../store.jsx`, `../lib/supabase.js`, `../lib/pricing.js`, `../lib/billing.js`, `../lib/tone.js`, `../hooks/useCountUp.js`, and sibling components `AiAssistant.jsx`; nothing inside this module imports back into them. Each file is self-contained and has no shared internal helpers beyond inline sub-components (`ScoreRing`, `BreakdownBar`, `FlagRow`, `NoResult`, `OffersContent`).
