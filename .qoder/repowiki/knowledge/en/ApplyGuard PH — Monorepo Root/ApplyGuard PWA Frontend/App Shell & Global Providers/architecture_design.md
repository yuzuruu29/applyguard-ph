Entry point `src/main.jsx` mounts the React tree under `StrictMode`, wraps it in `BrowserRouter`, imports `index.css` for Tailwind design tokens, and conditionally registers `/sw.js` as a PWA service worker. `src/App.jsx` is the root component that composes two context providers — `AuthProvider` (outer) then `AppProvider` (inner) — and declares all top-level routes (`/`, `/result/:id`, `/tracker`, `/settings`, `/offers`, `/account`, `/mock-interview`) with a shared `<Layout>` shell plus a catch-all `NotFound`. `src/auth.jsx` owns Supabase session lifecycle (`getSession` + `onAuthStateChange`), fetches entitlements and AI usage rows on login, and exposes derived tier/cap values; it must wrap `AppProvider` because `AccountPage` calls `useApp.notify`. `src/store.jsx` holds settings, jobs, last scan result, toasts, and an opt-in cloud sync engine: it reads `localStorage` once via `lib/storage`, debounced-persists changes, flushes on `beforeunload`/`visibilitychange`, pulls+merges remote state on login via `lib/cloud` + `lib/sync`, and pushes back after a first successful pull. `src/mobile.js` runs before React to detect the Capacitor runtime and dynamically import `@capacitor/status-bar` / `@capacitor/splash-screen`; it is a no-op in browsers. `src/index.css` defines the project's Tailwind v4 `@theme` tokens (paper/ink/brand/go-warn-stop palette, Fraunces/Hanken Grotesk/JetBrains Mono fonts) and reusable animation classes (`rise`, `settle`, `stamp-in`, `toast-in`, `scan-sweep`, `pulse-dot`, `page-enter`, `elev`, `paste-frame`, `field-frame`) with a `prefers-reduced-motion` block that zeroes durations/delays.
